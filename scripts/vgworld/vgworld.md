## 一、v4：星月夜与密植花田

### 1. 星月夜：不是抬头换一张贴图，而是走进另一种天光

此前天空的三组涡心都位于低空，抬头只能看到平蓝；白昼太阳与夜间月亮还会同时叠在天上。v4 做了三层改造：

- **局部画境昼夜**：以小镇为中心，48m 内完整进入星月夜，48–82m 平滑过渡；
  走近时天空、灯光、雾气、窗灯、萤火虫一起渐入夜色，离开后回到原来的收集昼夜进度。
  区域提示同步显示「走近小镇，天色入画」。这是局部氛围，不会消耗或改写 12 星辰的全局进度。
- **原画级星月夜天空**：将《星月夜》原画裁去白边、转为 JPEG 并内嵌进单文件 HTML，
  以透视方式挂在小镇北面天空；抬头可见原画的漩涡笔触、星晕与右上弯月，不再用规则图形模拟。
  画布外区域自动压暗并淡化程序化星晕，太阳只在白昼出现，不再日月同天。
- **前景与灯光**：小镇左侧补两棵火焰般的高柏树，夜间环境光与主光进一步压暗，窗灯更暖；
  泛光阈值提高且改为半分辨率，避免星星糊成大方块。

### 2. 向日葵：从 420 株散布，到约 2000㎡ 的密植花海

- 花田缩成椭圆（约 60×46m 外接范围），**2400 株**双层花瓣向日葵，密度约 1.2 株/㎡。
- 花盘增加内层花瓣与四种金橙变化；茎叶增加叶脉，另有 **900 株**底层阔叶填绿。
- 花盘朝向收拢到面向小径的一侧，高度带连续起伏，不再像随机插在地里的道具。
- 花海里留一条弯曲小径，把取景地、星辰与镉橙颜料串起来，仍能真正走进花田。
- 取景镜头改向花田中心，小地图同步改为椭圆花田。

### 3. 整体巡检中一并修复

- 麦田从 18000 增至 **24000 株**，并清出梵高、画架、取景地与颜料周围的空间，麦秆不再穿过人物面部。
- 泛光由 1/4 分辨率改为 1/2 分辨率、阈值 0.60→0.82、强度 0.75→0.58，保留灯月柔光而减少色块。
- 实测：小镇抬头可见天顶漩涡，离开小镇的麦田仍是白昼；花田远景连片、近景有叶层；
  梵高周围留白有效；真实开局与调试场景均零控制台报错。

## 二、v3 基础改造：人物、画质、操作与界面

用户此前的三条反馈——**人物粗糙、画质不够、玩起来缺少探索感与界面逻辑**——对应三组改造：

### 1. 人物：从「圆柱 + 球」到梵高时代的人

旧版 NPC 是圆柱身体加球头，站在麦田里像玩具。v3 重写为**程序化人形装配**，共 9 名：

| 部件 | 做法 |
|---|---|
| 双腿 | 髋部枢轴的独立腿组，含靴子；行走时前后摆动 |
| 躯干 | 上身 + 燕尾 + **马甲** + **翻领** + 纽扣，比例按 1.75m 成人重排 |
| 手臂 | 肩枢轴摆动，**袖口** + 手；持物手另有姿态 |
| 头部 | 脖、头、鼻、眼、眉、头发/发髻；男性带**锥形胡须 + 八字胡 + 鬓角** |
| 帽子 | 草帽 / 平顶硬草帽 / 圆顶礼帽 / 鸭舌帽 / 女式软帽 五种 |
| 道具 | 调色板（带颜料点与画笔）、阳伞、干草叉、提篮、**烟斗** |
| 落地感 | 每人一枚接触阴影贴片，不再「浮」在地上 |

场上分布：桥上两名行人、黄房子附近一男一女、村庄礼帽男子、河畔撑伞提篮女子、
麦田画架旁的**梵高本人**（蓝罩衫、草帽、红胡子、调色板、烟斗，4 句台词）、麦田农人、广场老妇人。
`animatePerson()` 驱动腿臂摆动、身体起伏、头部轻晃；行走者按路径往返，静立者朝向路人。

### 2. 画质：把「色块感」压下去

- **笔触材质升级**：`brushMat` 从 256 提升到 512×512、四层叠加（大笔触铺底 / 主笔触 / 厚涂高光 / 互补色点缀），
  并按表面尺寸设置 repeat（房屋 2–6、地面 52），近看不糊、远看有颗粒。
- **渲染链路**：`HalfFloatType` 渲染目标 + MSAA（2×/4× 随画质档），1/2 分辨率三通道泛光
  （阈值 0.82 提亮窗灯、星辰、月亮），后处理增加细节回填 0.15、抖动去色带。
- **灯光**：新增冷蓝补光 `rimLight` 勾勒轮廓；夜间新增 `AmbientLight` 抬升建筑暗面，
  月光方向改到照向村庄南立面——夜里房子不再是纯黑剪影，而是蓝紫的体块。
- **灰雾（底稿）修复**：原先半球灰雾的边缘会在天空切出一条巨大浅色三角。
  改为「上下渐隐 + 径向 rim 渐隐」的双重遮罩，只留贴地的一层薄雾。
- **夜空去环**：天空 shader 里的星晕原本带余弦环，远看像一圈圈气泡；改为平滑高斯，星点变成柔光。
- **移除探照灯**：星辰/颜料原本各有一根 26m 高的光柱，近看像玻璃箱、夜里像探照灯，已隐藏，
  改为光晕 + 地面光环 + 罗盘/小地图指引。
- **地表铺陈**：新增 2600 丛程序化野草（按 300 个簇心聚集，橄榄绿而非荧光绿）、
  460 朵小花、130 块半透明草地补丁，把村庄周围的大片砂土打散成普罗旺斯的郊野。
- **底稿调色**：未上色地表从灰白改成暖赭底稿（`terrainGray` 重新配比），首屏就是一张暖色油画底。
- 画质三档（暂停菜单可切）：流畅 0.55 / 均衡 0.8（MSAA2+泛光）/ 细腻 1.0（MSAA4+泛光）。

### 3. 操作与界面：从「能走」到「好走、看得懂」

**移动手感**
- 速度做加速度插值（地面响应 13/17，空中 5），松键有惯性滑行，不再瞬间启停。
- 跳跃加 **0.16s 输入缓冲 + 0.12s 土狼时间**，起跳初速 5.7，落地有镜头下沉 `landKick`。
- 头部 bob + 横向 sway + 轻微 roll；FOV 随状态变化（基础 72 + 疾跑 7 + 涉水 −2 + 摄影 +2）。
- 指针锁定失败自动降级为「按住拖拽转视角」；锁定时左键 = 交互，不必再按 E。

**界面状态机**（`title / play / card / vantage / pause / finale` 六态互斥）
- 对话卡、取景、暂停、终章各自接管输入与指针锁，Esc 逐层退出，不再互相打架。
- HUD 只在 play/card 显示；暂停/取景/终章自动隐藏 HUD，画面干净。
- **进度面板**：旅途百分比 + 星辰/颜料/足迹三行 pip（12/5/7 格）+「下一步」最近目标
  （名字、方向箭头、距离、副文案）。
- **顶部罗盘**：15° 刻度、N/E/S/W、视野内最近 4 个目标的图标与距离。
- **小地图**：仅 28m 内显影目标，保留「走过去才发现」的探索感。
- **图鉴**：带 7 幅原作缩略图的网格，未踏足处显示「?」；颜料清单显示所在画境。
- 暂停面板：画质、笔触浓度、鼠标灵敏度、视野、音量、旅途图鉴、回到村口。
- 摄影模式：上下黑边 + 隐藏 HUD，按 P 切换。

## 三、玩法结构（24 个探索点）

**「世界是一幅未完成的底稿，你是找回色彩的人。」**

1. **失落颜料 ×5** —— 群青（村庄）/ 铬黄（麦田）/ 镉橙（向日葵）/ 翠绿（河畔）/ 土赭（黄房子）。
   拾取后对应画境从暖赭底稿渐变为浓彩：灰雾散开、地表顶点色插值、建筑材质去色 uniform 归零、麦田/河面 uPainted 拉满。
2. **画家足迹 ×7** —— 每处画境一个金色光圈。站上去按 E，镜头自动转向当年梵高的构图，
   金色画框合拢，给出原作缩略图与创作故事（《星月夜》《麦田与柏树》《向日葵》《罗纳河上的星夜》
   《夜间咖啡馆》《黄房子》《特兰克泰尔桥》）。
3. **灵感星辰 ×12** —— 每拾一颗夜色推进 1/12：白昼钴蓝渐变为漩涡星云，窗灯与河灯亮起，萤火虫与蟋蟀浮现。
   集齐 12 颗触发终章《星月夜 · 完成》，星云全力奔涌；之后仍可继续漫步与摄影。

- 类型：第一人称步行探索，无战斗、无失败惩罚
- 时长：15–25 分钟全收集
- 情绪曲线：暖赭底稿 → 色彩逐块点亮 → 白昼入夜 → 星辰奔涌

## 六、技术要点

- **单文件、零外部资源**：three.js r187 从 jsDelivr 载入（附 cdnjs 备源与加载失败提示），其余全部运行时生成。
- **笔触系统**：Canvas 生成多方向短笔触贴图 → `MeshStandardMaterial`；地面 512 贴图 1500 条笔触、repeat 52。
- **底稿↔上色双态**：区域灰雾 dome、地形顶点色双缓冲、材质 `onBeforeCompile` 去色 uniform、
  自定义 shader 的 `uPainted`，全部随收集实时插值。
- **后处理**：方向性笔触 Kuwahara + 笔触颗粒 + 画布经纬 + 泛光 + 细节回填 + 抖动。
- **程序化天空**：白昼＝钴蓝短皴 + 奶油卷云；夜晚＝三漩涡域扭曲 fbm + 螺旋笔触环 + 高斯星晕 + 铬黄月亮。
- **程序化河面**：各向异性 fbm、煤气灯/月亮金色倒影、堤岸赭黄反光、饱和度提升。
- **人物动画**：层级组枢轴 + 正弦相位，腿/臂反相摆动，身体起伏与头部轻晃。
- **URL 调试入口**（开发用，不改代码即可跳点）：
  `梵高世界.html?x#auto&paint=all&at=x,z,yaw,pitch&night=0.8`
  注意：file:// 下只改 hash 不会重载，必须更换 `?v=` 查询串强制刷新。

## 七、v3 实测记录

浏览器（桌面 Chromium）实测，控制台零报错：

- 开局：标题 → 进入画布，HUD、罗盘、区域提示、「下一步」指引正常；出生点不再误触取景地。
- 人物：麦田梵高近景可辨认（草帽/红胡/蓝罩衫/马甲/翻领/调色板/烟斗）；桥上两人沿桥往返，双腿交替摆动。
- 收集：拾星辰 → HUD 1/12 + 语录卡；拾群青 → 1/5 + 上色卡，区域渐变压暗/变蓝。
- 取景：桥面按 E 触发镜头转向 + 金框 + 原作缩略图，计数 1/7。
- 界面：Esc 呼出暂停（无指针锁也可用）、面板不再溢出、HUD 正确隐藏；J 打开图鉴带缩略图网格；对话时提示条隐藏。
- 夜色：12 星推进后星云、窗灯泛光、月光蓝调成立；建筑暗面有蓝色层次，不再是纯黑剪影。

### 已知不足（下一版方向）

1. 建筑仍是低多边形体块，近看缺少檐口、窗棂、斑驳墙面等细节；下一步应把房屋升级为「体块 + 檐口/窗框/烟囱/爬藤」组合。
2. 人物是风格化人形，手指、面部结构仍简化；若要更「梵高时代」，可加围裙褶皱、帽檐阴影、布料笔触。
3. 村庄地面在大范围上仍偏空，草地补丁与野草密度可按区块再调。
4. 铁桥桥面笔触方向偏「水流」，可换成沿桥长的木板/铁板纹理。
5. MSAA4 + 泛光在集成显卡上的帧率未实测，低配建议默认「均衡」。
